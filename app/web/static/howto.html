1. L'idée : une petite rédaction de journal

L'app fonctionne comme une rédaction. Chaque personnage est un morceau de programme. Certains utilisent l'IA (un modèle de langage, souvent local via Ollama), d'autres suivent des règles fixes. Clique sur un personnage.

🤖 utilise l'IA⚙️ règles fixes, sans IA 🙋 humain🔌 service externe
L'IA ne peut pas inventer un lien. Elle ne renvoie que des numéros (« le document n°3 est intéressant ») : l'adresse, le titre et la date sont recopiés par le code depuis l'article collecté.
Rien ne part sans toi. La veille s'arrête et attend ta validation avant de publier. Ton commentaire devient une leçon pour la fois suivante.
Petit modèle, gros encadrement. Des règles vérifient tout ce que l'IA écrit : format, liens, dates, chiffres, citations mot pour mot.
🛰️

3. Le plan : un DAG (liste de tâches avec des flèches)

Avant de démarrer, la veille reçoit un plan : chaque tâche dit de quelles tâches elle dépend. Les flèches vont toujours dans le même sens, sans boucle : c'est un DAG (graphe orienté acyclique). Le superviseur lance chaque tâche dont les dépendances sont finies ; plusieurs peuvent partir en même temps. Clique sur une tâche pour la faire tomber en panne 💥, puis lance la simulation.

6. Les garde-fous : le « harness » de l'app

Un harness (harnais) est tout ce qu'on met autour de l'IA pour la tenir : consignes, formats imposés, contrôles automatiques, validation humaine. Choisis une bêtise que l'IA pourrait faire et regarde quelle couche l'arrête.

🤝

7. Claude Code : le harness du développeur

À ne pas confondre avec le chapitre 6. Ici, l'IA ne fait pas la veille : c'est Claude Code, l'assistant qui aide à développer l'app. Le dossier .claude/ l'encadre à son tour. Clique sur les moments d'une session de travail.

🌉 Le pont entre les deux mondes : les skills veille-tech et review-actu sont lues par Claude Code et par l'app elle-même (le Scout et le Reviewer les reçoivent dans leurs consignes). La mémoire de veille est aussi exportée dans .claude/memory/veille.md : chaque session Claude Code démarre en connaissant tes préférences.
