# Prompts de veille IA

Prompts cliquables dans l'onglet **📚 Knowledge**. `Cible : chat` envoie le prompt à
l'assistant de veille ; `Cible : review` le pose dans le chat de challenge d'une review.
Un prompt qui contient `{…}` est d'abord placé dans le champ de saisie pour être complété.

## Quoi de neuf cette semaine
Domaine : Transverse
Cible : chat
