 │ C'est quoi le KV cache et pourquoi il limite le serving ?                                                                                        │ 
 │                                                                                                                                                  │ 
 │ ✦ Veille  ✓ 📚 Base de connaissances · 4 entrée(s) de la base de connaissances pour « C'est quoi le KV cache et pourquoi il limite le serving ?  │ 
 │ »                                                                                                                                                │ 
 │ Le KV cache est une technique de mémorisation des keys et values déjà calculés lors de la génération de texte. Il permet d'éviter de les         │ 
 │ recalculer à chaque nouveau token, ce qui améliore la performance. Sa taille est un facteur limitant, notamment en termes de mémoire. [1]        │ 
 │                                                                                                                                                  │ 
 │ Plus précisément, la taille du KV cache est proportionnelle au contexte et au nombre de requêtes, ce qui peut devenir un goulot d'étranglement.  │ 
 │ [1]                                                                                                                                              │ 
 │                                                                                                                                                  │ 
 │ La gestion du KV cache est optimisée par la technique PagedAttention, introduite avec vLLM, pour réduire la fragmentation et augmenter le nombre │ 
 │ de requêtes servies en parallèle. [2]                                                                                                            │ 
 │                                                                                                                                                  │ 
 │ Pour optimiser l'inférence, il est crucial de considérer la précision, la taille de lot, les longueurs d'entrée/sortie, ainsi que l'utilisation  │ 
 │ de techniques comme la quantification (accompagnée d'une mesure de perte de qualité) ou GQA. [3][4]                                              │
